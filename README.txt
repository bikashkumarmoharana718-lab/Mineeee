BBY APOLOGY WEBSITE

Files:
- index.html
- style.css
- script.js

Optional files to add yourself:
- our-photo.jpg  -> your photo
- our-song.mp3   -> your music

How to run:
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Add your photo as "our-photo.jpg".
4. Add your song as "our-song.mp3".
5. Open index.html in a browser, or use the Live Server extension.
